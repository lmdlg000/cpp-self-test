# P8 · 方程求根器 Equation（多项式 + 牛顿迭代）

> 难度：★★★★　·　对应课件：第 2~8 周（循环与收敛判定、引用参数、类与资源管理、运算符重载、`const`、`std::string` / 函数模板）　·　构建：单文件 OJ（README 第 1.1 节）　·　提交文件：`P8.cpp`
>
> 通用约定（评测命令、输入/输出格式、禁用项、健壮性 R1~R9、评分）见 [README](README.md)；本文只写本题的额外要求。

## 1. 题目背景

数值课的第一个作业是"用手写牛顿迭代求方程近似根"：给一个方程 `f(x) = 0` 和一个初值 `x0`，反复做

```text
x(k+1) = x(k) - f(x(k)) / f'(x(k))
```

直到相邻两次的差 `|x(k+1) - x(k)|` 足够小。基础版只能对一个写死的函数求根；这次要把它**升级成一个能装任意多项式的求根器**：方程由输入的多项式系数给出，导数由程序自己算，求根器要能判断收敛、报告迭代次数，还撑得住"初值选在驻点""重根""根本没根"这些情况。请实现多项式类 `Equation`，把"存多项式、算值、求导、牛顿迭代求根、按数学写法打印"全部封装进去。

## 3. 必做接口

只需一个 `.cpp`（建议命名 `P8.cpp`），包含头文件、`Equation` 的定义与实现、以及下面给定的 `main`。

```cpp
#include <iostream>
#include <cstddef>
#include <cmath>
using namespace std;

class Equation {
    int     deg;    // 次数：规范后 deg >= 0；零多项式为 deg == 0 且 coef[0] == 0
    double* coef;   // coef[0..deg]，coef[0] 是最高次项系数，coef[deg] 是常数项
public:
    Equation();                                  // 零多项式
    Equation(const double* c, int d);            // 从 c[0..d]（高次在前）构造，含规范化
    Equation(const Equation& e);
    Equation& operator=(const Equation& e);
    ~Equation();

    int    getDeg() const;                       // 次数
    double operator[](int k) const;              // x^k 的系数，越界返回 0.0
    double operator()(double x) const;           // 代入 x 求值
    Equation derivative() const;                 // 导数
    int    solve(double x0, double& root) const; // 牛顿迭代：成功返回迭代次数，失败返回 -1

    friend ostream& operator<<(ostream& os, const Equation& e);
};
```

2 个数据成员（`deg`、`coef`）的**名字、类型、顺序不得改动**；11 个成员/友元函数的**签名不得改动**。可以另外增加 `private` 成员函数（例如私有的"逐项求导到数组"辅助），不影响判分。

**`main` 由题目给出，请原样粘贴，不得修改**：

```cpp
// ---------- 以下 main 由题目给出，不得修改 ----------
int main() {
    int q = 0;
    if (!(cin >> q)) return 0;
    for (int t = 0; t < q; ++t) {
        int n = 0;
        cin >> n;
        double c[8];
        for (int i = 0; i <= n; ++i) {
            cin >> c[i];
        }
        double x0 = 0.0;
        cin >> x0;

        Equation eq(c, n);
        cout << eq << endl;
        cout << eq.derivative() << endl;
        cout << eq.getDeg() << " " << eq[0] << " " << eq[eq.getDeg() + 1] << endl;
        double root = 0.0;
        int it = eq.solve(x0, root);
        if (it < 0) {
            cout << "FAIL" << endl;
        } else {
            cout << root << " " << it << endl;
        }
    }
    return 0;
}
```

`main` 每组数据固定做四件事：打印多项式、打印导数、打印"次数 / 常数项 / 越界系数"、牛顿求根。**任何对 `main` 的改动（包括多打一个空格、改 `using namespace`）都按 R8 处理。**

## 4. 输入格式

第一行一个整数 `q`（`1 ≤ q ≤ 200`），表示数据组数。

随后 `q` 组，每组一行（token 之间用任意空白分隔，见 README 第 2 节第 2 条）：

```text
n  c0  c1  ...  cn  x0
```

- `n`：多项式次数，`0 ≤ n ≤ 6`；
- `c0 … cn`：从**最高次到常数项**的系数，都是**整数**（可带负号，可能含前导 `0`，见第 6 节第 1 条）；
- `x0`：牛顿迭代的初值，**实数**（可能带小数、可能为负）。

## 5. 输出格式

每组数据输出**四行**：

1. **多项式的规范文本**（规则见下）；
2. **导数的规范文本**（同规则）；
3. `deg c0 c越界`：三个数，空格分隔 —— 依次是 `eq.getDeg()`（规范化后的真实次数）、`eq[0]`（**常数项**）、`eq[eq.getDeg() + 1]`（必然越界，恒为 `0`）；
4. **求根结果**：成功时 `root k`（近似根 + 迭代次数，空格分隔）；失败时**单独一行** `FAIL`（三个大写字母，不带任何数字）。

多项式/导数的文本规则（`operator<<`）：

- 零多项式（所有系数都是 0）打印 `0`；
- 从**高次到低次**逐项输出，**系数为 0 的项跳过**；项与项之间**不空格**；
- **首项**系数为负时直接写 `-`，为正时不写符号；**非首项**用 `+` / `-` 连接；
- 次数 `p ≥ 1` 且系数绝对值为 `1` 时**省略系数**：`x^3`、`-x`、`+x`；
- 次数 `p = 1` 写 `x`（**不写 `x^1`**）；次数 `p ≥ 2` 写 `x^p`；次数 `0` 只写系数的绝对值；
- 系数用 `cout` 的**默认格式**输出（6 位有效数字）；**不要** `fixed` / `setprecision`。

`3 1 0 -2 -5` → `x^3-2x-5`；`2 -1 0 1` → `-x^2+1`；`1 1 -2` → `x-2`；`1 0 5` → `5`；`0 0` → `0`。
近似根同样用默认格式（6 位有效数字），行末不要多余空格，末尾只有一个换行；不要输出任何提示语。

## 6. 计算规则与约束

1. **规范形式（存储不变式）**：
   - `deg >= 0`，`coef` 是一块长度 `deg + 1` 的 `new double[]`；
   - `deg > 0` 时 `coef[0] != 0`（**去掉高次的前导 0 系数**）；
   - **零多项式**固定写成 `deg == 0`、`coef[0] == 0`；
   - 例：`n = 4` 输入 `0 0 1 -2 -5` → 真实次数 `2`，文本 `x^2-2x-5`；`n = 3` 输入 `0 0 0 0` → 零多项式，文本 `0`。
2. **`Equation(const double* c, int d)`**：从 `c[0..d]` 构造并**立刻规范化**（跳过前导 0；全 0 或 `d < 0` 得到零多项式）。`main` 里的 `c` 是栈数组，构造函数必须**把系数拷进自己的堆缓冲**，不能保存 `c` 的地址。
3. **`Equation()`**：零多项式（`deg = 0`、`coef[0] = 0`）。`derivative()` 对常数方程要用到它。
4. **`operator[](int k)`**：返回 `x^k` 的系数（`k = 0` 是常数项，`k = deg` 是最高次项）。`k < 0` 或 `k > deg` 时返回 `0.0`，**且不访问 `coef`**（R6）。注意内部是按**高次在前**存的：`x^k` 的系数是 `coef[deg - k]`。
5. **`operator()(double x)`**：代入求值，建议用 Horner 法（从最高次开始 `r = r * x + c`），`deg + 1` 次乘法，不要逐项算 `pow`。
6. **`derivative()`**：逐项求导（`c * x^p` → `p * c * x^(p-1)`），返回**新的** `Equation` 对象；
   - 常数方程（`deg == 0`）的导数是**零多项式**，打印 `0`；
   - 返回对象会走拷贝构造 / `operator=` 的路径，**浅拷贝在这里就是 double free**（R5）。
7. **`solve(x0, root)`（牛顿迭代）**，严格按下面的顺序执行，一步都不能省：
   - 记 `x = x0`，`k` 从 `1` 开始；
   - 算 `fx = f(x)`、`dfx = f'(x)`；
   - **若 `fabs(dfx) < 1e-12`** → 切线水平，迭代无法继续：`root = x`，返回 `-1`；
   - 算 `xn = x - fx / dfx`；**若 `fabs(xn - x) < 1e-10`** → 收敛：`root = xn`，返回 `k`；
   - 否则 `x = xn`，`k` 加一，回到上一步；
   - `k` 超过 `100` 仍未收敛 → `root = x`，返回 `-1`。
   - **迭代次数 `k` 的含义**：第 `k` 次执行"算 `xn`"这一步后得到的 `xn` 就是 `xk`；收敛时返回的 `k` 是**做出最后那次更新时的编号**（`x0` 不算迭代）。
8. **失败（`FAIL`）的三种来源**：导数绝对值小于 `1e-12`（初值恰在驻点、常数方程）、迭代 100 次仍未满足收敛条件、以及由此产生的数值发散。失败只打印 `FAIL`，**不打印迭代次数、不打印诊断**（诊断若要打必须进 `cerr`）。
9. **数值约定**：全部用 `double`（不要用 `float` 省事，也不要拿 `int` 存系数）；允许用 `<cmath>` 的 `fabs`。系数是整数，但中间结果与根都是浮点数。
10. **第 8 周内容的使用许可（本题特批）**：本题排在字符串与模板那一讲之后，所以下面这些**允许使用**——
    - `#include <string>` 与 `std::string`（拼多项式文本、拼输出都行），`#include <sstream>` 与 `stringstream`（把系数转成文本再拼）；
    - **函数模板**：愿意的话可以把"代入求值""逐项求导""牛顿迭代"写成 `template <typename T>` 的通用版本，再用 `double` 实例化；也可以用 `template <typename T, int N>` 的常量模板参数。**不强制**，用不用都不影响判分；
    - `#include <fstream>`（本地调试时从文件读数据用得上，提交的代码仍然从 `cin` 读）。
    **仍然禁止**：`vector` / `map` / `array` 等 STL 容器、`auto`、范围 `for`、`lambda`、智能指针、`<bits/stdc++.h>`；`rand` / `srand` / `time`（本题必须**确定性**收敛，同一输入两次运行输出必须一致）。
    另外：**三个阈值请用 `const double` / `const int` 定义，不要用 `#define`**（第 8 周 *#define is bad*：宏是文本替换，`#define EPS 1e-10` 一旦参与复杂表达式就会算错，而且没有类型检查）。`<cmath>` 只用 `fabs` 就够，求值用 Horner + 累乘，不必用 `pow`。
11. **文件划分**：本题是**单文件题**，类定义、成员实现、`main` 全在一个 `.cpp` 里，不要拆 `.h`。

**【样例 1 诊断】**（stderr，评测忽略）：无输出

**【说明】**

- **第 1 组**：`x^3-2x-5`，导数是 `3x^2-2`（中间项的 0 被跳过，`3x^2` 的系数 3 保留），从 `x0 = 2` 出发 5 次迭代收敛到 `2.09455`（真实值 2.094551481…，6 位有效数字）。第 3 行 `3 -5 0` 分别是次数 3、常数项 -5、越界的 `eq[4]` 给 0；
- **第 2 组**：`x^2-2` → 根 `1.41421`（√2）；导数是 `2x`，注意**系数 2 不能省**；
- **第 3 组**：线性方程 `2x-4` → 根 `2`，但迭代次数是 **2**：第 1 次得到 `x1 = 2`（`|Δx| = 2` 还比较大），第 2 次 `x2 = 2`、`Δx = 0` 才判定收敛——线性方程总要多一次"确认"；
- **第 4 组**：`(x-1)^2 = x^2-2x+1` 是**二重根**，牛顿法在这里退化成线性收敛（误差每次减半），要 28 次才收敛；根打印成干净的 `1`（说明收敛后误差远小于 6 位有效数字）；第 3 行 `2 1 0` 是次数 2、常数项 1、越界 0；
- **第 5 组**：`x^2-x` 从 `x0 = 0` 出发——**初值本身就是根**，第 1 次更新 `Δx = 0` 立刻收敛，`0 1`；
- **第 6 组**：`x^3-3x+1` 从 `x0 = 1` 出发，此时 `f'(1) = 3 - 3 = 0`（初值恰在**驻点**，切线水平），按第 6 节第 7 条**立即判失败**，只打印 `FAIL`。

- **第 2 组（常数方程）**：`5 = 0` 没有根，导数是零多项式（打印 `0`），`f'` 恒为 0 → `FAIL`；
- **第 3 组（零多项式）**：`n = 3` 但系数全 0 → 规范化成 `0`，导数也是 `0`，`FAIL`；第 3 行 `0 0 0`；
- **第 4 组（负号与省略 1）**：`-x^2+1` 的首项系数是 -1 → 打印 `-x^2`（省掉 1，保留负号），导数是 `-2x`；

- **第 6 组（远初值）**：同一个 `x^3-2x-5`，初值从 2 改成 100，根一样（`2.09455`）但迭代次数变成 **15**。

## 8. 健壮性要求

通用要求见 README 第 4 节，本题额外/重点要求：

- **R1（多组数据）**：一个进程内连续处理 `q` 组，每组独立；不许把"上一次的根"当这一次的初值，也不许用全局/`static` 变量跨组传递中间状态。
- **R2（非法数据）**：本题输入保证合法（`0 ≤ n ≤ 6`、系数是整数），**不需要**读入诊断；数值上的"算不下去"由第 6 节的 `FAIL` 规则处理，不用 `cerr`。
- **R3（边界）**：常数方程、零多项式、线性方程、二重根、初值恰为根、初值恰为驻点、远初值（`x0 = 100`）、前导零系数、负数根、`n = 0`、`q = 1`。
- **R4（动态内存）**：`new double[]` ↔ `delete[]` 严格配对；`derivative()` 里为返回对象新分配的缓冲不能漏；`derivative()` 内部的临时数组要么用栈数组、要么 `delete[]` 干净。用 `valgrind --leak-check=full --error-exitcode=1 ./a.out < in.txt` 或 `g++ -g -O1 -fsanitize=address,undefined` 自测（R7），要求 **0 errors、0 leaks**。
- **R5（资源三件套）**：本题**有堆成员**，析构 + 拷贝构造 + `operator=` 必须齐全且正确（深拷贝、自赋值安全）；`derivative()` 的返回值、`Equation d = eq.derivative();` 这类写法全靠它们。
- **R6（越界不访问内存）**：`operator[]` 越界（负数、`k > deg`）返回 `0.0`，不得读 `coef`、不得断言；`main` 里有一处必然越界的调用。
- **R8（不改 `main`）**：原样粘贴，输出格式不得改动；调试输出只能进 `cerr` 并记得删。
- **本题额外要求**：收敛判据与阈值必须与第 6 节**逐字一致**（`1e-10` / `1e-12` / 100 次），迭代次数的口径不能差 1——判分是逐字符比对，`5` 与 `6` 就是 WA。

**甲方保证**：`1 ≤ q ≤ 200`；`0 ≤ n ≤ 6`；系数是整数且 `|c| ≤ 100`；`|x0| ≤ 1000`；同一输入两次运行结果完全一致。**甲方不保证**：首项系数非 0（会有前导 0）；方程有实根；初值一定收敛；初值不在驻点上；根是"好看"的数（可能是 `3.44949` 这种）。

## 9. 自测清单

- [ ] `x^3-2x-5`、`x0 = 2` → `2.09455 5`；改成 `x0 = 100` → `2.09455 15`（根一样，次数变）；
- [ ] `x^2-2`、`x0 = 1` → `1.41421 5`；导数打印 `2x`（系数 2 不能省）；
- [ ] `2x-4`、`x0 = 0` → `2 2`（线性方程多一次确认迭代）；
- [ ] `(x-1)^2`、`x0 = 0` → `1 28`（二重根，线性收敛，次数比一般情况大很多）；
- [ ] `x^2-x`、`x0 = 0` → `0 1`（初值即根）；

## 10. 常见错误

1. **忘记规范化**：`0 0 1 -2 -5` 存成 4 次多项式，`getDeg()` 打印 4、文本开头多出 `0x^4+0x^3`、导数也错。
2. **`operator[]` 的索引方向搞反**：内部是"高次在前"，`x^k` 的系数是 `coef[deg - k]`；写成 `coef[k]` 会让"常数项"打印成最高次系数（样例第 1 组第 3 行立刻对不上）。
3. **`operator[]` 忘记越界判断**：`eq[deg + 1]` 读到堆外，`-fsanitize=address` 会报 heap-buffer-overflow；规格要求返回 `0.0`。
4. **Horner 写错**：`r = r * x + c[i]` 的初值必须是 `0`、从 `i = 0`（最高次）开始；从常数项开始累就会算成另一个多项式。
5. **导数漏项或次数错**：`deg` 次多项式求导得 `deg - 1` 次，循环上界写成 `<= deg` 就多算一项；常数方程求导要得到**零多项式**而不是"次数 -1"（`deg == -1` 会让 `operator<<` / `[]` 全线越界）。
6. **`derivative()` 返回局部指针 / 浅拷贝**：`Coef*` 指向函数内的栈数组，或返回对象与 `*this` 共用 `coef` → 析构两次、double free（R5）。
7. **`operator=` 先 `delete[] coef` 再从 `e` 拷贝**：`eq = eq;` 自赋值时 `e.coef` 已悬空。
8. **`operator<<` 首项符号处理错**：首项为正也印 `+`（`+x^3-2x-5`），或首项为负印成 `-1x^3`。
9. **忘记省略系数 1**：`1x^3-2x-5`、`-1x^2+1`；注意"系数绝对值等于 1 **且次数 ≥ 1**"才省略，常数项 `1` 要照常打印。
10. **次数 1 写成 `x^1`**；次数 0 写成 `5x^0`。
11. **阈值写成 `1e-8` / `1e-6`，或把 `1e-10` 记成 `1e-12`**：迭代次数会明显变少或变多（样例第 4 组 28 次对阈值极敏感，隐藏用例更是照妖镜）。判据必须是 `fabs(xn - x) < 1e-10`——`<` 与 `<=` 只在恰好命中边界时才不同，但规格写的是 `<`，照写不吃亏。
12. **先判收敛再判导数**：顺序反了会在驻点处先算出 `xn = inf`，随后 `fabs(inf - x)` 不满足阈值，一路跑到 100 次才 `FAIL`——结果同样是 `FAIL`，但如果你顺手把 `inf` 打进输出就错了。按第 6 节第 7 条的顺序来。
13. **`solve` 用返回值带回根**：签名固定是 `int solve(double x0, double& root) const`，根走**引用参数**，返回值是迭代次数 / `-1`。
14. **`solve` / `derivative` / `operator()` 漏写 `const`**：`main` 里 `eq` 不是 `const` 对象，漏了也能编译通过，但签名与题面不符（属评分"规范"扣分），而且对 `const Equation` 就调不了。
15. **迭代次数差 1**：`x0` 不算迭代；第 `k` 次"算 `xn`"之后才 `k` 有值。样例第 3 组的 `2 2` 就是这条的照妖镜。
16. **失败时也打印根**：规格是失败只印 `FAIL` 一行。
17. **用 `float` 或 `int` 存系数/根**：`3.44949` 这类根用 `float` 只剩 6~7 位精度，迭代次数会飘。
18. **用 `#define` 写阈值**：`#define EPS 1e-10` 是文本替换，`1 / EPS`、`EPS * EPS` 一掺进表达式就容易算错，而且报错信息里全是 `1e-10` 看不懂（第 8 周 *#define is bad*）。用 `const double eps = 1e-10;`。
19. **`std::string` 拼文本时忘了"省略系数 1"只在次数 ≥ 1 时生效**：`to_string(1) + "x^3"` 会把 `x^3` 变成 `1x^3`；常数项 `1` 反而要照常打印。本题允许用 `string`，但格式规则一条都不能少。
20. **改动 `main`**：哪怕"只是加个空格"也按 R8 算。
