# P5 · 有理数类 Rational

> 难度：★★★★　·　对应课件：第 6~7 周　·　构建：单文件 OJ（README 第 1.1 节）　·　提交文件：`P5.cpp`
>
> 通用约定（评测命令、输入/输出格式、禁用项、健壮性 R1~R9、评分）见 [README](README.md)；本文只写本题的额外要求。

## 1. 题目背景

一个"分数练习册"程序要记录并把玩精确的分数：`1/3 + 1/6` 必须得到 `1/2`，不能像 `double` 那样丢精度。请你实现一个有理数类 `Rational`：它在内部始终保存**最简形式**（分母恒为正、分子分母互质），支持四则运算、复合赋值、取负、六种比较，并能把结果以 `num/den` 或整数的文本形式输出。

## 3. 必做接口

只需一个 `.cpp`（建议命名 `P5.cpp`），包含头文件、`Rational` 的定义与实现、以及下面给定的 `main`。

```cpp
#include <iostream>
#include <cstddef>
using namespace std;

class Rational {
    long long num;   // 分子（带符号）
    long long den;   // 分母，恒 > 0，且已约分
public:
    Rational(long long n = 0, long long d = 1);
    long long getNum() const;
    long long getDen() const;
    Rational operator+(const Rational& o) const;
    Rational operator-(const Rational& o) const;
    Rational operator*(const Rational& o) const;
    Rational operator/(const Rational& o) const;
    Rational& operator+=(const Rational& o);
    Rational operator-() const;                     // 取负
    bool operator==(const Rational& o) const;
    bool operator!=(const Rational& o) const;
    bool operator<(const Rational& o) const;
    bool operator<=(const Rational& o) const;
    bool operator>(const Rational& o) const;
    bool operator>=(const Rational& o) const;
    const char* toCString(char* buf, int size) const;   // 把文本形式写入调用者的 buf（含 '\0'），返回 buf
    friend ostream& operator<<(ostream& os, const Rational& r);
};
```

2 个数据成员（`num`、`den`）的**名字、类型、顺序不得改动**；17 个成员/友元函数的**签名不得改动**。可以另外增加 `private` 成员函数（例如统一做约分的 `void normalize();`、私有的 gcd），不影响判分。

**`main` 由题目给出，请原样粘贴，不得修改**：

```cpp
// ---------- 以下 main 由题目给出，不得修改 ----------
int main() {
    int q = 0;
    if (!(cin >> q)) return 0;
    for (int t = 0; t < q; t++) {
        long long n1 = 0, d1 = 1, n2 = 0, d2 = 1;
        cin >> n1 >> d1 >> n2 >> d2;
        Rational a(n1, d1);
        Rational b(n2, d2);
        cout << a << " " << b << endl;
        cout << (a + b) << " " << (a - b) << " " << (a * b) << " " << (a / b) << endl;
        cout << (a == b) << " " << (a < b) << " " << (a <= b) << " "
             << (a > b) << " " << (a >= b) << " " << (a != b) << endl;
        Rational c = a;
        c += b;
        char buf[64];
        cout << c << " " << (-a) << " " << a.toCString(buf, 64) << endl;
        char tiny[2];
        a.toCString(tiny, 2);
        a.toCString(NULL, 0);
    }
    return 0;
}
```

`main` 里的最后两次 `toCString` 调用（`tiny` 只有 2 字节、还有一次 `NULL` + `0`）**结果不参与输出**，它们是"不许越界写"的自检：只要你的实现按第 6 节的规则处理了 `size` 和 `NULL`，这两行就是静默的；写漏了就会破坏内存（ASan/valgrind 会报错，严重时直接崩溃）。

## 4. 输入格式

第一行一个整数 `q`（`1 ≤ q ≤ 200`）。

随后 `q` 行，每行 4 个整数：`n1 d1 n2 d2`，表示 `a = n1/d1`、`b = n2/d2`。整数之间用任意空白分隔（行数与分组不必严格对应，见 README 第 2 节第 2 条）。

## 5. 输出格式

对每组数据输出**四行**：

1. `a b`：两个有理数的文本形式。
2. `a+b a-b a*b a/b`：四个运算结果（空格分隔）。
3. `a==b a<b a<=b a>b a>=b a!=b`：六个 `0/1`，**单空格**分隔。
4. `c -a toCString(a, 64)`：其中 `c = a; c += b;`，`-a` 是 `a` 的相反数，第三个是 `toCString` 写入 `buf` 后的文本。三者空格分隔。

文本形式的规则：**分母为 1 时只写分子**（`3`、`-3`、`0`），否则写 `num/den`（`-3/4`、`1/2`）。行末不要多余空格，末尾只有一个换行；不要输出任何提示语。

## 6. 计算规则与约束

1. **规范形式**：任何 `Rational` 对象在构造完成、运算完成之后都必须满足
   - `den > 0`；
   - `gcd(|num|, den) == 1`；
   - `num == 0` 时固定写成 `0/1`（`den == 1`）。
   例：`2/-4` → `-1/2`；`-6/-8` → `3/4`；`0/-5` → `0/1`。
2. **必须自己写 gcd**（欧几里得算法，`while (b != 0) { t = a % b; a = b; b = t; }`），**禁止** `std::gcd` / `<numeric>`。取绝对值时注意 `long long`。
3. **构造函数** `Rational(n, d)`：
   - `d == 0` → 输出诊断 `cerr << "invalid: zero denominator" << endl;`，对象规范化为 `0/1`；
   - 否则：`d < 0` 时先把符号搬到分子（`num = -num; den = -den;`），再约分。
4. **四则运算**：结果同样必须是最简形式（最省事的做法是让构造函数完成规范化）。除法要单独判断 `o.num == 0`：输出诊断 `cerr << "invalid: divide by zero" << endl;` 并返回 `0/1`。
5. **`operator+=`**：返回 `*this` 的引用（形如 `c = a; c += b;` 才能用），并且**自己也要规范化**。
6. **一元 `-`**：只翻转分子，分母保持正。
7. **比较**：用交叉相乘 `num * o.den` 与 `o.num * den` 比较（不要转成 `double`，`1/3` 与 `333333/1000000` 这种数转浮点会判错）。
8. **`toCString(buf, size)`**：
   - 先把文本写进自己的临时 `char` 缓冲，再按 `size` 拷进 `buf`；
   - 保证结果以 `'\0'` 结尾；`size` 装不下时**截断**（不是溢出写）；
   - `buf == NULL` 或 `size <= 0` 时**什么都不写**，直接返回 `buf`；
   - 返回 `buf`。
9. **数值范围**：甲方保证 `0 ≤ |n| ≤ 10^6`、`1 ≤ d ≤ 10^6`；比较只发生在由输入构造出来的 `a`、`b` 上，交叉相乘不超过 `10^12`；运算中间量不超过 `2 · 10^12`，`long long` 完全够用。**但请你一律用 `long long`**，并且"先约分、再相乘"，别用 `int`。
10. **禁止**：`std::string`、`to_string`、`vector` 等 STL 容器与字符串设施；`std::gcd` / `<numeric>`；`auto`、范围 `for`、`lambda`、`template`、`<bits/stdc++.h>`；`rand` / `srand` / `time`。**`toCString` 里不许用 `sprintf` / `snprintf` / `std::to_string`** —— 本题就是要练"整数 → 字符"的手写（第 7 周 `char` 处理），用十进制取余 + 逆序填字符即可。

## 8. 健壮性要求

通用要求见 README 第 4 节，本题额外/重点要求：

- **R1（多组数据）**：一个进程内连续处理 `q` 组，每组独立，不允许出现"上一组的状态污染下一组"（例如把约分用到的临时变量写成全局/`static`）。
- **R2（非法数据）**：分母为 0、除以 0 用 `cerr` 提示后**规范化为 `0/1` 继续**（不要 `continue` 掉整组：`main` 还要用 `a`/`b` 算后面几行），`stdout` 完全不受影响。
- **R3（边界）**：`q = 1`、`0/1`、`-1/1`、`1/-1`、两个 10^6 量级的数、相等（`3/4` 与 `6/8`）、`a` 与 `b` 互为相反数。
- **R5（拷贝语义）**：本题的 `Rational` **没有堆成员**，默认的拷贝构造与 `operator=` 就是正确的，不需要自己写；`main` 里的 `Rational c = a;` 只是普通拷贝。
- **R6（越界/非法参数不得访问内存）**：`toCString` 在 `size` 太小时截断、`buf == NULL` 或 `size <= 0` 时不写；`getNum`/`getDen` 只读自身成员。
- **R8（不改 `main`）**：`main` 原样粘贴，输出格式不得改动。
- **本题额外要求**：`toCString` 的截断与 `NULL` 处理（`main` 末尾有两次静默自检）；必须手写 gcd 和整数 → 字符转换。

**甲方保证**：`1 ≤ q ≤ 200`；每行恰好 4 个整数，满足 `0 ≤ |n| ≤ 10^6`、`|d| ≤ 10^6`（`d` 可能为 0 或负数，见 R2）。**甲方不保证**：`d` 一定非 0、一定为正；分子分母已经互质；不会出现除以 0。

## 10. 常见错误

1. **忘记"分母恒正"**：`2/-4` 直接存成 `2/-4` 或 `-2/4`，打印成 `2/-4`，样例立刻对不上。构造时先搬符号再约分。
2. **忘记约分**：`2/4 + 3/6` 得到 `12/24` 而不是 `1`。
3. **`num == 0` 没统一成 `0/1`**：`0/5` 打印成 `0/5`。
4. **gcd 只处理正数 / 忘记取绝对值**：`-2/4` 的 `-2 % 4 = -2`，若不取绝对值会得到负的"最大公约数"，约分后分母变成负数。
5. **比较时转 `double`**：`1/3` 与 `333333/1000000` 会被判相等；一律交叉相乘。
6. **`operator+=` 返回 `void` 或返回局部对象**：`c = a; c += b;` 与链式调用都会失败；必须 `Rational&` + `return *this;`。
7. **`operator+=` 忘了规范化**：`c` 会变成没约分的分数（例如 `1/2 += 1/3` 得到 `10/12`）。
8. **除法没判 `o.num == 0`**：`den = den * o.num` 得到 0 分母，后面的构造会连锁报警（样例第 4 组专门考这个）。
9. **`toCString` 直接 `while (n > 0) buf[k++] = ...`**：没有检查 `size`，遇到 2 字节缓冲就写越界；也没有 `NULL` / `size <= 0` 的判断（`main` 里有这两次调用）。
10. **截断后没补 `'\0'`**：`buf` 不是字符串，`cout << buf` 会读越界。
11. **用 `sprintf` / `to_string`**：本题禁止；手写十进制取余 + 逆序填字符。
12. **`const` 漏写**：所有比较、`getNum`、`getDen`、`toCString` 都是 `const` 成员函数，签名里已经有尾 `const`，实现时删掉就编译不过。
13. **`friend` 写错**：`operator<<` 必须在类里用 `friend` 声明并且**不带 `Rational::`**；返回 `ostream&` 并 `return os;`，否则 `cout << a << " " << b` 无法链式输出。
