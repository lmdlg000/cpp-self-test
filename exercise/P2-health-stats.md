## 1. 题目背景

体检中心把一批测量值（整数，`0 ~ 200`）录入程序，需要报出最小值、最大值、平均值，以及"去掉一个最高、一个最低"后的修正平均和中位数，用于快速判断这批数据是否异常。

## 3. 必做接口

```cpp
int    readValues(int* a, int cap);
void   minMax(const int* a, int k, int& lo, int& hi);
double average(const int* a, int k);
void   sortAsc(int* a, int k);
double medianSorted(const int* a, int k);
double trimmedSorted(const int* a, int k);
```

六个函数的签名**固定，不得改名、不得增删参数、不得改返回类型**。语义如下：

- **`readValues`**：从键盘**恰好读入 `cap` 条整数记录**（每条记录占一个输入名额，读完即处理）。值不在 `0..200` 的记录执行 `cerr << "invalid: " << x << endl;` 后跳过，**不写入数组**；合法记录依次写入 `a[0]`、`a[1]`、…。返回写入数组的**有效个数 `k`**（`0 <= k <= cap`；`cap == 0` 时一条不读、返回 0）。下标只增到 `k - 1`，**不能把非法值的位置留空**。
- **`minMax`**：求 `k` 个有效值的最小值 `lo` 与最大值 `hi`，通过引用参数带回；`k == 0` 时 `lo = hi = 0`。不得修改数组（`const int*`）。
- **`average`**：返回 `k` 个有效值的算术平均；`k == 0` 返回 `0.0`，不得除零。不得修改数组。
- **`sortAsc`**：把 `a[0..k-1]` **原地升序排序**。必须自己写排序（插入 / 选择 / 冒泡均可，`k <= 1000` 时 `O(k^2)` 足够），**禁止 `std::sort`** 及任何 STL 排序。
- **`medianSorted`**：入参数组**已经升序**；`k == 0` 返回 `0.0`；`k` 为奇数取正中间那个，`k` 为偶数取中间两个数的平均（注意用 `/ 2.0`）。
- **`trimmedSorted`**：入参数组**已经升序**；去掉一个最小值和一个最大值后，对剩下的求平均；`k <= 2` 时直接等于 `average(a, k)`。`k == 0` 返回 `0.0`。
- **调用关系**：`main` 读 `K`、用 `new int[K]` 申请原始数据，调用 `readValues` 得到有效条数 `k`；`minMax` / `average` 用原始数组；再申请 `new int[k]` 作为排序副本，复制后 `sortAsc`，交给 `medianSorted` / `trimmedSorted`；最后输出三行并 `delete[]` 两块数组。

## 4. 输入格式

- 输入是**空白分隔的整数 token**，不要依赖换行结构（README 第 2 节第 2 条）。
- 第 1 个整数 `K`（`0 <= K <= 1000`）：记录条数（就是 `readValues` 的 `cap`）。
- 随后**恰好** `K` 个整数测量值，每个占一条记录（可能越界，越界即为非法记录）。
- `K = 0` 时第一个 token 之后没有任何记录。

## 5. 输出格式

输出**三行**，数字之间用**一个空格**分隔：

```text
最小 最大
平均 修正平均
中位数
```

- 所有浮点数用 `cout` **默认格式**输出（6 位有效数字），**不要**用 `fixed` / `setprecision`（README 第 2 节第 4 条）。
- `k == 0` 时输出固定为：

  ```text
  0 0
  0 0
  0
  ```

- 行末不要多余空格，末尾不要多余空行，不要输出任何提示语。

## 6. 计算规则与约束

- **`readValues`**：恰读 `cap` 条记录；`x < 0` 或 `x > 200` 视为非法，用 `cerr` 提示后跳过（不写入数组）。返回有效条数 `k`。非法记录同样占用 `K` 中的一个名额，所以 `k` 可以小于 `K`。
- **`minMax`**：`k == 0` 时 `lo = hi = 0`；否则遍历求最小、最大。
- **`average`**：`k == 0` 时返回 `0.0`；否则 `sum / k`，**用 `double` 累加**（不要用 `int` 求和后整除，否则小数被截掉）。
- **`sortAsc`**：必须自己写排序，**禁止 `std::sort`**（README 第 3 节禁用项）。排序范围只有 `a[0..k-1]`，不能越界。
- **`medianSorted`**：入参已升序。`k` 为奇数 → `a[k/2]`；`k` 为偶数 → `(a[k/2 - 1] + a[k/2]) / 2.0`（**除以 `2.0`**，否则会丢小数）；`k == 0` → `0.0`。
- **`trimmedSorted`**：入参已升序。`k <= 2` → 等于 `average(a, k)`；否则把 `a[0]` 与 `a[k-1]` 各去掉一个，对中间 `k - 2` 个数求和后除以 `k - 2`。`k <= 2` 时**不要**执行"去掉两个再除以 `k - 2`"的分支（会除零或负下标）。
- **`main` 的内存**：原始数组 `new int[K]`、排序副本 `new int[k]`，两块都要 `delete[]`，**严格配对、只释放一次**；`k == 0` 时不申请排序副本（或零长分配后照样 `delete[]`）即可，不允许访问空指针元素。
- 只用 `cin` / `cout` / `cerr`；只许课件头文件（本题 `<iostream>` 足够），不要 `<bits/stdc++.h>`。
- 禁用 STL 容器、`std::string`、`auto`、范围 `for`、`lambda`、`template`、`std::sort`（README 第 3 节）。
- 禁止 `rand()` / `srand()` / `time()`（README 第 3 节），结果必须确定。
- 不要把六个函数的 `const int*` 参数改成 `int*`；不要修改函数签名。
- 浮点数不要用 `==` 直接比较（第 2 周 *Error float point ==*）。

## 8. 健壮性要求

本题额外要求（通用条目见 README 第 4 节；R9 是多文件题的要求，本题不涉及）：

- **R2**：越界测量值用 `cerr` 提示后跳过，`stdout` 不受影响；不得写入数组，不得参与任何统计。
- **R3**：必须处理 `K = 0`、`K = 1`、`K = 2`、`K = 3`、全部非法、所有值相同、偶数中位数等边界；`k = 0` 时六个函数与三行输出都要有确定值。
- **R4**：原始数组与排序副本都用 `new[]` 申请、`delete[]` 释放，严格配对；无 leak、无 use-after-free、无 double free；`k == 0` 时不分配排序副本或零长分配后安全释放。
- **R6**：`readValues` 写入下标不得超过 `cap - 1`；`medianSorted` 偶数分支取 `a[k/2 - 1]` 时不得越界；`trimmedSorted` 的 `k <= 2` 分支必须在除法之前返回。
- **R8**：三行输出、数字顺序、空格、换行都不得改动。
- **R7（本地）**：用 `valgrind --leak-check=full --error-exitcode=1` 或 `-fsanitize=address,undefined` 自测，要求 0 errors、0 leaks；`K = 1000` 时也要正常跑完。

**甲方保证**：

- `0 <= K <= 1000`；输入恰好包含 `K` 条整数记录；没有多余数据；输入不会被读坏。
- 合法测量值的范围是 `0 ~ 200`。

**甲方不保证**（必须自己防守）：记录可能全部或部分非法（`k != K`）；`K` 可能为 0；均值 / 中位数可能恰好是整数，`cout` 默认格式输出 `66` 而不是 `66.0`，这是正确输出。

## 10. 常见错误

- `k == 0` 时仍然执行 `sum / k`、访问 `a[0]` 或 `a[k/2]`：除零、越界，直接崩溃或输出 `nan`（README 第 4 节 R3）。
- 用 `int` 求和后 `sum / k` 丢掉小数：例如 `237 / 5` 在 `int` 下是 `47`，正确是 `47.4`。
- 偶数中位数写成 `(a[k/2 - 1] + a[k/2]) / 2`，整数除法把 `.5` 截掉；应除以 `2.0`。
- 复制排序副本时用了 `K` 而不是有效条数 `k`，把非法记录或未初始化的元素也排进去。
- `trimmedSorted` 对 `k <= 2` 仍执行"去掉两个、除以 `k - 2`"：除以 0 或负数，或访问 `a[k-2]` 越界。
- 忘记 `#include <iostream>` 之外还要写 `using namespace std;` 导致 `cin` / `cout` 找不到；或漏写函数原型（第 3 周 *Parameters not match*）。
- 用 `std::sort` 或任何 STL 排序（README 第 3 节明确禁用）。
- `new int[K]` 后只 `delete[]` 了一块数组（排序副本泄漏），或写了 `delete a`（`new[]` 必须配 `delete[]`，第 3 周 *Common Errors 3*）。
- `readValues` 里把非法值也写进数组（`a[k]` 与 `a[i]` 用混），导致数组里混入越界数据。
- `minMax` 对 `k == 0` 没有给 `lo` / `hi` 赋 0，输出未初始化值。
- 用 `fixed` / `setprecision` 输出，导致与题面样例不一致（README 第 2 节第 4 条）。
- 把六个函数的 `const int*` 改成 `int*`（签名不得改动；`const int*` 也表示函数内不修改数组）。
- 输出顺序写错（三行分别是 极值 / 平均与修正平均 / 中位数），或多输出一行提示语。
